# YouthLink Uganda – Project 2 Website

**Module:** Internet Technology & Web Design  
**Institution:** Makerere University  
**Group Project 2 – November 2026**

## What this is
A complete, hand-coded multi-page website that implements the Information Architecture and Content Inventory from Group Project 1.

## Pages (7 linked pages)
| File | Page | Suggested owner focus |
|------|------|-----------------------|
| index.html | Home | Hero, stats, featured cards |
| jobs.html | Jobs & Internships | Listings, filters, apply CTAs |
| skills.html | Skills & Training | Programme cards, skills-gap notes |
| guidance.html | Career Guidance | CV tips, interview advice, resources |
| mentors.html | Mentors & Stories | Success stories, mentor profiles |
| about.html | About / Contact / FAQ | Mission, contact form, FAQ, sources |
| css/styles.css | Shared stylesheet | Layout, components, responsive rules |

## Technical notes
- Pure HTML5 + CSS (no frameworks, no page builders, no JavaScript required for core use)
- Semantic structure (`header`, `nav`, `main`, `footer`, `article`, etc.)
- Mobile-first responsive design (Flexbox + CSS Grid)
- Consistent navigation and footer on every page
- Accessible basics: language attribute, aria labels, focus styles, sufficient colour contrast
- Sample content is fictional and clearly marked for educational use

## How to view locally
1. Unzip the folder.
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari).
3. Navigate using the top menu.

## How to host (for marks)
Upload the entire folder (keeping the `css` subfolder) to any static host such as:
- GitHub Pages
- Netlify (drag-and-drop)
- Cloudflare Pages
- InfinityFree / AwardSpace (free PHP/static hosts)

The site must be reachable via a public URL without login.

## W3C validation
Validate each HTML file at https://validator.w3.org/ and the CSS at https://jigsaw.w3.org/css-validator/.  
The code is written to pass without errors when validated as HTML5.

## Group contribution reminder
Every student must be able to explain and modify the page/section they own. Bring source files to the presentation.
